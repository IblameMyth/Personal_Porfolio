# Mithilesh Laddha - Personal Portfolio

A sleek, responsive, single-page personal portfolio website built with modern HTML5 and custom CSS3. Designed with a dark mode aesthetic, dynamic CSS conic-gradient skill rings, and smooth scrolling navigation.

---

## 🚀 Live Demo

- **GitHub Repository**: [IblameMyth/Personal_Porfolio](https://github.com/IblameMyth/Personal_Porfolio)

---

## ✨ Features

- **Responsive Design**: Custom CSS grid and flexbox layouts optimized for mobile, tablet, and desktop screens.
- **Dynamic Skill Rings**: Custom CSS variables (`--value`) combined with `conic-gradient()` to dynamically showcase skill proficiency percentages.
- **Clean Sectioning**:
  - **Hero**: Overview, social links, and quick stats.
  - **Services**: Modern card layout displaying core capabilities.
  - **About Me**: Brief bio, education history, and achievements (e.g., Top 10 in Tadoba Hackathon 2025).
  - **Skills**: Interactive progress rings for technologies (HTML, CSS, JS, Figma, Canva, SQL, Python).
  - **Portfolio**: Direct links to featured GitHub projects (ExpenseWise, Inventory System, TaskNet).
  - **Contact**: Social icons, direct email, and phone contact info.
- **Embedded Icons**: Uses FontAwesome 6 for crisp vector social media icons.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup for accessibility and clear structure.
- **CSS3**: Custom CSS variables, CSS grid/flexbox, radial/conic gradients, and media queries for responsiveness.
- **FontAwesome 6**: For social media and UI icons.
- **Google Fonts**: Uses *Space Grotesk*.
